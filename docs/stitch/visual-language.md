# Oh-My-AIHub

## Overview

芥末与墨的贴纸风。暖色点阵纸面上，圆角表面像贴上去的纸片，配清晰墨线、右下硬投影、圆润厚实的标题与数字。气质亲切，有秩序，适合处理真实业务。

延续这一品牌识别，自由发展适合新设计的构图、空间密度、控件用法、插画和动效。现有卷角贴纸 O 标志可作为品牌图形的起点。

## Colors

芥末是主色，薄荷、浅蓝、粉色辅助表达状态和数据。浅色是暖纸与深墨，深色是暖调墨夜，两套主题保持一致的识别感。配色以清楚的文字、数字和状态为目标。

## Typography

标题和关键数字圆润厚实，可参考 Baloo 2 与源泉圆体。正文采用适合长时间阅读的字体，地址、凭据和标识使用清楚的等宽字形。具体字体搭配与字号层级由设计决定。

## Layout

构图、导航、页面组织和密度随各端任务设计。用对齐、分组与留白建立清楚层级，让主要操作容易发现，长内容、表格与表单保持可读。

## Elevation & Depth

清晰的墨线和向右下偏移的硬投影是主要层次语言。贴纸之间有足够呼吸空间，表面内部用轻量分隔组织内容。按压时可以让贴纸轻轻贴回纸面。

## Shapes

以圆角贴纸与胶囊形控件建立亲和力，具体轮廓与比例服务于新设计。业务表面端正、对齐，保持整体秩序。

## Components

主次操作清楚，输入有可见标签，状态结合文字与颜色表达。卡片、列表、表格、表单和弹层共享同一种贴纸语言。兼顾键盘、触屏、焦点、对比度与减少动态效果，让交互反馈清楚自然。
