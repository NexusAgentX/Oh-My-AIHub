# 保留芥末与墨的贴纸风

请延续 Oh-My-AIHub 现有贴纸风的识别感，在这个基础上自由发展适合新产品的视觉系统。

## 品牌识别

- 暖色点阵纸面，墨线描边，向右下偏移的清晰硬投影。
- 芥末作为主色，圆角贴纸与胶囊控件，标题和关键数字有圆润厚实的气质。
- 薄荷、浅蓝、粉色辅助表达状态与数据；文字和数字清楚易读。
- 浅色是暖纸与深墨，深色是暖调墨夜。两套主题延续同一种品牌感。

这些特征构成贴纸风的核心。页面构图、空间密度、控件形状的具体用法、插画和动效可以由你探索，让整体既有亲和力，也适合处理真实业务。

## 视觉方向

以纸面、描边与硬投影建立层次，保持干净、有秩序的手作感。业务内容有清楚的主次，表格和长表单也能轻松阅读。把贴纸语言用在适当的地方，给内容足够空间。

品牌名为 **Oh-My-AIHub**。现有标志是中间带 O 的芥末卷角贴纸，可作为视觉识别的起点。圆体标题可参考 Baloo 2 与源泉圆体，正文采用适合长时间阅读的字体；具体字体搭配由你决定。

附后的浅色与墨夜配色来自现有品牌，可作为设计起点。欢迎围绕识别感和可读性调整配色组合与使用方式。

## 顺手与可读

请综合考虑触达距离、操作次数、清楚的文字层级、可识别的状态、键盘与触屏、对比度、焦点和减少动态效果等体验。让常用任务容易发现，让重要操作有明确反馈，让长内容和长名称也保持可用。

通过主要页面建立一致的视觉语言。
