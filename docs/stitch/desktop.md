# Google Stitch：独立设计桌面应用

请以产品设计师和交互设计师的身份，为 Oh-My-AIHub 构想新的桌面体验。后附产品简报说明核心业务与自由度，贴纸风说明提供品牌起点。

目标是一个适合长时间使用的桌面应用，并考虑通过 PWA 安装到电脑后的独立窗口体验。你可以重新决定页面数量、工作区、导航、布局与流程，提出更好的产品组织方式。

## 值得探索的方向

- 让成员容易开始接入 API，也容易回来查看花费、调用和自己的渠道。
- 利用桌面空间支持比较、对照和连续工作，例如模型报价、渠道状态、交易和资料审核。多栏、列表详情联动、就地编辑等形式都可按任务选择。
- 鼠标和键盘都操作顺手，重要操作靠近相关内容；在任务间切换、下钻和返回时保持方向与上下文。
- 安装成独立窗口后，用户仍能理解当前位置、返回上级和管理账户。窗口缩放或并排使用时，关键工作依然顺畅。
- 公共资料的编辑就近发生在实体详情中，把查看、维护和审核结果连接起来。

围绕简报中的核心任务发挥产品与交互判断，具体实现形式由你决定。
