# Google Stitch：独立设计原生感移动 PWA

请以产品设计师和交互设计师的身份，为 Oh-My-AIHub 独立构想移动体验。后附产品简报说明核心业务与自由度，贴纸风说明提供品牌起点。

把它想象成安装在手机主屏幕上、日常随手打开的应用。从手机的使用情境重新组织产品：首页、页面数量、导航、详情和操作流程都由你设计，移动端可以拥有与桌面端完全不同的结构。

## 值得探索的方向

- 成员随手查看余额、处理积分交易、复制接入信息、检查调用和管理自己的渠道。
- 适合单手触达、容易理解层级，返回时能接上原来的任务。主要操作的位置稳定，内容和操作各有清楚空间。
- 为触屏设计列表、详情、选择和编辑，按复杂度决定全屏任务、就地操作或底部面板，形成适合手机的任务节奏。
- 输入法、系统安全区、应用挂起和恢复都能自然融入体验。用户站外付款后回到原交易，容易知道进展和下一步。
- 从主屏幕打开应用时，能够顺利开始或接上自己的任务。
- 公共资料的编辑从相应实体详情开始，在手机上也能顺畅地修改和提交。

围绕简报中的核心任务发挥产品与交互判断，具体导航形态、步骤和页面数量由你决定。

先提出属于手机的产品组织和主要页面关系，再用连续原型表达核心任务。展示有代表性的浅色与墨夜页面，并让主要流程体现原生应用的节奏。

请给出自然、顺手的移动应用骨架，通过主要页面和代表性状态表达整体体验。
