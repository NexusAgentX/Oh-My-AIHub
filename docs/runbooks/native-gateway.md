# 原生图片与会话代理

平台入口以 OpenAPI 的实际 `paths` 为准；发现矩阵也包含后续 Feature 的设计，不能凭矩阵宣称端点已开放。请求使用平台 API Key，网关换用渠道的上游 Key；不使用宿主登录或官方订阅账号。

## 资源与分页

资源由创建操作建立账号/平台 Key 归属，渠道来自当前已批准分组。换 Key、模型/渠道治理或删除分组后，新资源操作仍检查当前权限和原凭据范围；不会在另一供应商寻找同名 ID。后台已经登记的工作继续以原快照收尾，这不恢复消费者的访问权限。

原生 ID 冲突会隔离旧归属，返回不可用时先检查调用、渠道状态和受保护元数据；不要直接 SQL 改归属、把外部 ID 认领到账号或更换共享凭据试读。元数据不保存会话、图片、文件、工具结果或密文正文，也不提供从历史日志恢复正文的功能。

OpenAI 范围内列表只返回本人条目，`first_id`/`last_id` 对应可见条目；继续读取使用响应的 `next_cursor` 作为下一次的 `after`，其余筛选参数保持一致。标准 SDK 也可用已核验归属的可见 ID 作为 `after` 或 `before`，不能使用共享账号中其他人的 ID。反向分页沿用原 `before` 条件，并将保护后的继续游标传入 `after`。扫描预算用完可能返回空 `data` 和非空 `next_cursor`，此时使用该保护游标继续。Gemini 的 `nextPageToken` 同样是保护后的值，作为 `pageToken` 原样回传。换平台 Key、父级、筛选条件或实际模型上下文后旧游标无效。

没有明确模型的辅助操作先按有效能力、Key 权限和渠道状态筛选，自动模式缺少可比模型指标时按稳定渠道 ID 排序；手动模式需要适用的已保存顺序。无候选时检查缺失的有效能力证据，不以旧报告、未知结果或其他模型的价格强行兜底。

## Codex 身份与会话上下文

身份辅助接口只认证当前平台 API Key，返回本平台命名空间中的本人标识、空邮箱和未知套餐 `aihub`。消费者在固定客户端的 `personal_access_token` 字段填写自己的平台 Key 时，CLI 会把认证归类为 ChatGPT；这不代表官方订阅或 Pro 权益。身份接口不选择渠道、不读取共享上游身份、不产生上游费用，账号或 Key 撤销立即生效。

固定 notes/history 接口必须提供 `context.session_id` 与 `context.current_agent_name`。会话编号映射到当前平台账号＋Key 的保护范围；同一范围跨分组、渠道、凭据保持一致，另一个账号/Key 无法通过相同编号读取原内容。接口按当前能力和偏好重新选择候选，不登记历史来源粘性；独立标准远端资源引用仍核验原归属。操作自身和上下文隔离都需要有效支持证据，未知不放宽；笔记、历史、密文和原生 JSON 结果不落库，响应禁止共享缓存，元数据操作不套用一个虚构模型收费。

## 图片与计费

图片生成支持原生 JSON，图片编辑/变体支持原生 JSON 或单次 multipart；multipart 不写临时文件，仅替换模型字段。返回的图片 URL 不会自动成为网关下载入口，也不依赖独立 Files API。

账单只根据可靠用量及实际成功产物计算，`n` 是请求参数，不是已成功的产物数。SSE 的 partial 图片不收费为成功图片。没有实际 token 速度就不显示图片 token/s。计数、读取、取消、列表、metadata、会话/items 管理不重复收取原推理费；Compact 等计算仍使用正常同步原子结算。

## 运行上限与故障

请求传输支持 identity/zstd 单一编码，压缩前后均限制为 32 MiB。每进程至多同时执行两个编码/解码操作，无排队，每次操作限 2 秒，解码窗口至多 32 MiB、解码器内存保护 64 MiB。饱和返回 `request_codec_busy`，取消/超时返回 `request_codec_timeout`；这些本地失败不改变渠道健康，也不换渠道重做编码。缺少当前 zstd 支持证据的候选不能承接压缩请求。无压缩及无 Codex 上下文的路径不复制请求或 Header。

会话命名空间根使用已有密钥环加密持久化；备份及恢复沿用数据库与密钥环的成套备份。缺少历史包装密钥时修复密钥环，不删除保护根或重新生成会话命名空间。平台 Key 改变会进入独立笔记/历史编号范围，同一平台 Key 的编号不因渠道切换而改变。实际开放的 Codex 端点仍只以 OpenAPI `paths` 为准，底层转发机制不代表固定客户端专项已验收。

资源元数据使用两条独立数据库连接，SQL 操作有 5 秒上下文，回收事务另限 5 秒。辅助请求最多 32 个同时准入，另受账号在途和渠道并发/RPM 限制，无额外无界队列；分页每次请求至多扫描 4 页、每页最多 100 条和 1 MiB，共用实际出站尝试预算。饱和或预算耗尽返回明确错误或保护后的继续游标。

需要登记的 JSON 和非流式图片响应最多在内存暂存 32 MiB；流式资源先登记完整事件的 ID 后交付。失败时不能把未登记的 ID 当成可用资源。创建/修改结果未知时不自动重复写；不要把客户端超时理解成上游没有执行。后台已登记调用在登记暂时失败时仍负责原 Key、原价格的终态观察和结算；发现 ID 冲突时不读取或取消歧义对象。

生产迁移/清理和部署需维护者另行决定。开发不运行端到端性能 A/B，发版前按 [网关性能基线](gateway-baseline.md) 集中覆盖：无状态请求的引用扫描、资源登记/碰撞、受保护分页、图片 JSON/multipart/SSE、后台恢复和同步结算；开发阶段仅保留相关功能、SQL/分配成本回归及快速微基准。
