# ADR-0046：固定候选报价并在账本锁前认领调用内执行收据

- 状态：已通过
- 日期：2026-10-18
- 关联内容：Epic #487、Feature #491、ADR-0044

## 背景

同一模型 ID 的不同分组报价可以不同。图片、子推理和调用内工具可能同时有可靠计量，个别缺价或缺用量不能抹掉其他可靠部分。相同上游执行又可能被多次观察；进程内去重不能防止并发结算或重启后重复收费。

## 决定

候选快照持有不可变分组报价簿。调用固定该快照、开始时间、汇率与折扣；结算不查询当前目录，也不借用其他分组或原厂参考价。子模型按同组精确模型 ID 或唯一上游 ID 归属；有歧义则未计价。单位报价与条件档均按存储顺序首个实际条件匹配项生效，默认行放在例外后。token 与单位组件保留精确成本，合并后对成本、手续费分别取整；普通单 token 组件直接使用既有计算器，避免额外精确分数组合。

新建或运行周期费用只接受本次响应中可验证事实。首次观察执行 ID 不代表新建；没有可靠事实就记录未计价原因，不访问范围外管理 API 补计量。执行收据是用途根密钥保护的固定摘要，归属上游分组引擎、实际凭据、执行标识和计费周期；渠道及同组 CF/CDN 地址不是边界，平台账号/Key 不能让同一上游执行重复收费。摘要不出现在公开报价快照，不保存代码或工具正文。

仅携带收据的调用在同一事务内先锁定仍未关闭的调用，按固定顺序认领收据，再排除已计价组件、更新价格快照、关闭调用并执行既有账本过账。所有这些工作都在账本账户加锁前完成；账户锁后仍只有既有分录写入与提交。失败整体回滚，重复关闭不认领新收据。普通调用不查询收据表。

## 后果

收据随调用和账本保留，不是可浏览的工具资源目录。新增编号迁移不能丢弃已有收据。新账单附分组/报价版本、可靠单位与未计价原因，历史快照保留旧解码。收据调整后的实际费用必须回传内存预算/观测，不能继续使用调整前总额。接口接入和实际协议事实由对应 Feature 验证；本决定不授权生产切换或重算历史。
