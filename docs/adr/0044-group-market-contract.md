# ADR-0044：分组市场采用稳定对象、不可变报价与能力证据绑定

- 状态：已通过
- 日期：2026-10-18
- 关联内容：Epic #487、Feature #489、ADR-0012、ADR-0020、ADR-0040

## 背景

维护者要求取消全局模型上架前置，由用户贡献供应商分组及报价。地址可共享和重排，分组默认配置动态继承，报价更新不能重写在途调用和历史账单。旧业务配置允许在切换时清理，历史账本、账户与余额必须保留；当前新增结构需要保持每个中间合并阶段可启动。

## 候选方案

- 保留全局模型并同步分组报价：容易沿用旧接口，但恢复了维护者取消的上架前置，且同 ID 多报价仍需另一套归属。
- 将分组和报价存为任意 JSON：快速扩展，但数据库无法校验引用、价格单位、并发参考源或外键边界。
- 稳定对象加类型化关系和不可变报价：需要明确的迁移与快照组装，能够分别校验数据、连接配置、价格和能力证据。

## 决定

采用第三种方案。供应商/分组/模型/地址及地址关系各有稳定 ID，模型 ID 保持原生字符串而不指向全局模型主表。报价、条件档、token 细分与调用内工具单位价采用类型化字段，价格以九位定点金额保存；当前模型引用自己所属的不可变报价版本。

批准对象的修订存数据库类型化行快照。公开贡献层持有事务，在同一事务检查权限、基准修订和检测完整性后发布。数据库约束负责规范化地址唯一、父子归属、有效参考源竞争与业务删除边界。空值继承和明确空配置块分别表示。

能力摘要排除地址/报价/显示信息，报告绑定能力摘要和范围/代码/参数/凭据版本。连接变化、价格变化和能力失效分别处理；不因同组入口改变或报告年龄自行改变支持结论。直接上游、平台代理、固定 CLI 的证据层分开保存。

## 后果

新结构先追加，旧消费者随后按 Feature 边界切换；最终旧结构删除与切换同批完成，无长期双写或全局价格兜底。数据库和领域测试验证并发冲突、明确空值、不可变报价与删除保全。转发使用预先组装的快照，目录组装不进入逐次网关读路径。

版本表和不可变报价会随批准变更增长，需要沿用历史保留与备份策略；不能将数据库物理级联用于授权的业务清理。受保护游标/会话命名空间根密钥复用现有加密密钥环封装，密钥环轮换与命名空间身份稳定性分开。

## 替代关系

当前仅建立新数据契约，不改变仍在运行的旧定价与渠道消费者；不取代 ADR-0012 的条件选档算法、ADR-0020 的调用方事务原则或 ADR-0040 的快照不变量。旧模型/渠道定价归属在最终消费者切换时另行更新其替代关系。
