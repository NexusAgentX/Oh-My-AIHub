# ADR-0007：采用受邀身份与服务器端 Cookie 会话

- 状态：已通过
- 日期：2026-09-02
- 决策者：仓库维护者
- 关联内容：[Feature #21](https://github.com/NexusAgentX/Oh-My-AIHub/issues/21)、[SECURITY.md](../../SECURITY.md)

## 背景

平台不开放注册，管理员需要直接创建小圈子账户并线下交付初始凭据。用户首次登录必须换掉初始密码，账户停用或改密应立即使既有会话失效。浏览器控制台与未来平台代理 API Key 是不同凭据边界，不应把可长期离线使用的自包含浏览器令牌暴露给前端脚本。

## 决策目标

- 初始密码只展示一次，数据库、日志和后续接口都不能恢复明文。
- 密码、会话、首次改密、停用和管理员权限由后端强制执行。
- 改密与会话撤销具备原子性，停用账户不能继续使用既有会话。
- 浏览器不需要在 JavaScript 中持有会话令牌。

本决策不解决自助注册、自助找回、邮箱验证、第三方登录、多因素认证或平台 API Key。

## 候选方案

### 方案一：浏览器保存自包含 JWT

服务端查库较少，但撤销、停用和密码版本需要额外黑名单或短有效期；令牌进入 Web Storage 时也会扩大脚本泄漏面。

### 方案二：服务器端不透明会话与安全 Cookie

浏览器只持有随机 Cookie，数据库保存摘要和账户关联。每次请求查询当前账户状态，可直接执行撤销、首次改密和权限门禁。

### 方案三：接入外部身份提供商

可获得成熟认证能力，但引入外部账户、邮箱或租户依赖，与首版管理员直接创建用户名账户的边界不匹配。

## 决定

采用方案二。

- 密码使用 Argon2id 不可逆哈希；初始密码由密码学安全随机源生成，只在创建响应中返回一次。
- 会话令牌使用 32 字节密码学随机数，数据库只保存 SHA-256 摘要、账户、密码版本和到期时间；默认有效期为 24 小时。
- 浏览器通过 Host-only、`HttpOnly`、`SameSite=Lax` Cookie 携带会话，互联网部署默认要求 `Secure`。
- 非安全 HTTP 方法必须通过同源 `Origin` 校验。后端而非前端负责身份、首次改密和管理员权限门禁。
- 改密必须验证当前密码并拒绝复用；密码版本、新哈希、旧会话撤销和新会话创建在同一事务完成。
- 停用账户无法通过现有会话继续访问；管理员不得停用自己或最后一个启用管理员。
- 初始管理员由只接受交互式密码输入的本地命令在空系统中创建一次，不提供默认账号或环境变量明文密码入口。

## 后果

### 正面影响

- 前端脚本不能读取会话 Cookie，服务端可以立即撤销会话。
- 首次改密、停用、权限和密码版本始终以数据库当前状态为准。
- 不需要引入外部身份系统即可满足受邀小圈子的首版流程。
- 初始凭据与普通会话具有明确且可审计的生命周期。

### 负面影响与成本

- 每个受保护请求都需要访问服务器端状态数据库。
- 多实例登录限流和会话清理需要后续共享机制或定期任务；当前限流只在单进程内有效。
- 管理员遗忘密码后的恢复流程尚未定义。

### 风险与缓解措施

- **CSRF**：使用 SameSite Cookie，并对所有状态变更请求严格校验协议和 Host 相同的 `Origin`。
- **密码破解**：Argon2id 使用受控内存成本，统一未知账户和停用账户错误，并限制失败登录频率。
- **会话泄漏**：数据库只保存摘要，Cookie 禁止脚本读取且生产只经 HTTPS 发送，响应禁止缓存。
- **改密竞态**：使用密码版本比较与事务替换；只有一个并发改密可以成功。
- **管理员锁死系统**：禁止自停用和停用最后一个启用管理员；恢复流程在发布前另行定义。

## 验证方式

- 单元测试覆盖密码规则、Argon2id 验证器边界、随机初始密码和会话令牌摘要。
- PostgreSQL 集成测试覆盖首次登录、强制改密、旧密码与旧会话失效、停用账户失效、并发改密和管理员保护。
- HTTP 测试覆盖 Cookie 属性、同源拒绝、限流、首次改密门禁和普通账户管理员拒绝。
- 浏览器验收覆盖登录、首次改密、账户设置、管理员创建账户和只展示一次的凭据页。
