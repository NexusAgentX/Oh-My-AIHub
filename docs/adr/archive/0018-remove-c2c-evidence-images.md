# ADR-0018：移除 C2C 付款截图与争议证据图片

- 状态：已通过
- 日期：2026-10-07
- 决策者：仓库维护者
- 关联内容：[Feature #111](https://github.com/NexusAgentX/Oh-My-AIHub/issues/111)、[Epic #109](https://github.com/NexusAgentX/Oh-My-AIHub/issues/109)；部分取代 [ADR-0011](0011-adopt-c2c-order-trade-hold-state-machine.md) 中与证据图片相关的内容

## 背景

ADR-0011 允许买家声明付款时上传付款截图、争议双方上传证据图片，并为其设计了图片净化、独立加密、授权下载与 180 天密文销毁。截图不能触发自动放行，只是人工核实的辅助材料，却带来了图片解析攻击面、额外的敏感数据存储与清理流程，以及前后端的上传、预览和下载路径。维护者在全面重构（Epic #109）中决定移除这项能力。

## 决策目标

- 争议与付款声明只依靠文字陈述和账本、交易事件记录。
- 不再接收、保存或提供任何付款截图或争议证据图片。
- 不影响卖单支付方式的收款码：收款码仍按 ADR-0011 的净化、加密与授权规则保存和读取。

不解决：C2C 状态机、持有关系、仲裁动作与其他私密资料的生命周期，这些保持 ADR-0011 的决定不变。

## 候选方案

### 方案一：保留截图为可选能力

维持现状。继续承担图片处理攻击面和数据保管成本，而截图对人工仲裁的增益有限。

### 方案二：移除截图与证据图片，只保留文字陈述

缩小攻击面与敏感数据范围，简化交易与争议界面；管理员依据双方文字陈述、交易事件与账本记录仲裁，必要时在平台外核实。

## 决定

采用方案二。删除 `c2c_evidence` 表及其触发器与函数（迁移 `0008`），删除证据下载接口；付款声明与争议改为纯 JSON 文字提交，追加陈述接口改为 `POST /api/c2c/trades/{tradeID}/statements`。收款码及其图片净化保持不变。

## 后果

### 正面影响

- 平台不再保存付款截图这类高敏感个人图片，争议数据只剩文字陈述。
- 交易与争议流程、API 与界面更简单。

### 负面影响与成本

- 仲裁时缺少平台内的图片证据，需要依赖双方陈述或平台外核实。
- 迁移 `0008` 的 Down 只重建空表结构，无法恢复已删除的证据数据。

### 风险与缓解措施

- 误删收款码：迁移只删除证据表，集成测试断言 `qr_available` 列保留。

## 验证方式

- PostgreSQL 集成测试断言迁移后 `c2c_evidence` 不存在、收款码能力保留。
- 浏览器验收付款文字声明与文字争议流程，以及收款码上传与展示。

## 替代关系

部分取代 ADR-0011 中关于付款截图、争议证据图片的上传、净化、下载与销毁的内容；ADR-0011 其余决定继续有效。
