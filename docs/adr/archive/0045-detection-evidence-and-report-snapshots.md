# ADR-0045：检测证据按层留存，审核引用不可变报告

- 状态：已废弃
- 日期：2026-10-18
- 关联内容：Epic #487、Feature #490、ADR-0044

## 背景

创建执行全部保留场景，但负向结果不阻止审核。执行器可能取消、重启或部分复测；同组共享引擎证据不应变成逐地址或逐 Key 全测。供应商实际协议、平台代理和固定官方 CLI 的结论必须分开，合成机制结果不能证明真实供应商支持。已审核记录不能随下一轮复测被覆盖。

## 候选方案

- 用任务当前状态作为报告：实现简单，但复测会改变审批所依据的事实，缺注册项容易被误当作完整。
- 持久化所有原始流量：利于回放，但违反正文与凭据保护边界，也扩大资源占用。
- 固定 manifest、类型化断言/执行证据和不可变报告：保留必要来源与计量，增加完整性与版本核验。

## 决定

采用第三种方案。任务保存计划和最新进度，每轮结束另追加不可变报告；审批引用报告 ID，任务 ID 用于执行控制。执行请求和各轮场景结果也追加留存，报告固定目标、能力摘要、范围/执行代码/参数及凭据来源。

manifest 明确必需证据层与条件断言，缺实现不从分母删除。实际执行可以共享请求，但各断言分别核验并引用真实执行；上游负向结论、任务执行完整性和真实创建资格分别判断。合成来源不满足真实创建资格，不以单层成功概括 Codex。

专用凭据只留活跃任务内存，报告不含正文或原始诊断文本。变更凭据时关联新任务，保留旧来源，复用不依赖该凭据的有效引擎证据；凭据相关项与缺失内存产物的必要前置重跑，不伪称同一凭据，也不要求每 Key 全测。标准远端资源清理保持本任务可证明归属和原凭据范围。

## 后果

报告、执行元数据及版本会随检测增长，需要与配置历史一并备份。暂停/取消不是完整报告；无法恢复的原凭据资源仍如实保留清理状态。新执行代码或能力输入不兼容时保留历史报告但拒绝作为当前证据。F4/F8 负责实际协议断言与客户端取证，F2 负责审批绑定，F12 验证最终闭环。
